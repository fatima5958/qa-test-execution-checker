# QA Test Execution & Coverage Checker

A beginner-level Python project created to practice software testing and QA automation concepts.

## Project Purpose

This project simulates a simple QA test execution process. It checks the testing environment, executes predefined test cases, calculates test results, and reports basic test coverage.

## Features

- Browser support check
- Automation environment readiness check
- Reusable test execution function
- Test case execution
- PASS/FAIL result tracking
- Pass and fail percentage calculation
- Basic test coverage evaluation
- Tester information collection

## Test Cases

The project currently includes:

- Login
- Logout
- Add to Cart
- Search
- Checkout
- Profile

## Technologies

- Python
- Git
- GitHub
- Software Testing Fundamentals
